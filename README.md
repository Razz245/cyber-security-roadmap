> 🚀 A Complete Roadmap to Learn Cyber Security from **Beginner to Advanced** — including stages, labs, tools, and weekly learning plans.

---

## 🔰 Stage 1: Cyber Security Basics
🎯 **Goal:** Build a strong foundation.

**Learn:**
- What is Cyber Security & CIA Triad  
- Types of Hackers (White, Black, Grey Hat)  
- Cyber Attack Types (Phishing, DDoS, Malware, SQLi)  
- Networking Basics (IP, DNS, HTTP/HTTPS, Ports, Protocols)  
- Linux Fundamentals (Commands, permissions, users, root)  
- Virtualization (VirtualBox, VMs, Snapshots)

🧪 **Practice:**
- [TryHackMe – Intro Rooms](https://tryhackme.com)  
- [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/)  
- Setup **Kali Linux + VirtualBox**

---

## ⚙️ Stage 2: Networking & Operating Systems
🎯 **Goal:** Understand how systems communicate.

**Learn:**
- TCP/IP, Subnetting, VPNs, Firewalls, NAT  
- Windows & Linux privilege management  
- Shell scripting basics  

🧰 **Tools:**
Wireshark · Nmap · Netcat · tcpdump  

💡 **Labs:**
- Packet capture in Wireshark  
- Network scan using Nmap  

---

## 🧰 Stage 3: Ethical Hacking & Penetration Testing
🎯 **Goal:** Learn offensive security fundamentals.

**Learn:**
- Phases of Hacking (Recon → Scanning → Exploit → Maintain → Clear)  
- Vulnerability Scanning  
- Exploitation Basics  

🧰 **Tools:**
Metasploit · Burp Suite · SQLmap · Nikto · Hydra  

🧪 **Labs:**
- Exploit DVWA / bWAPP  
- Practice Metasploit modules  

---

## 🌐 Stage 4: Web Application Security
🎯 **Goal:** Master modern web vulnerabilities.

**Learn:**
- OWASP Top 10 (SQLi, XSS, CSRF, IDOR, etc.)  
- Cookie & Session management  
- Web interception, Bug bounty workflow  

🧰 **Tools:**
Burp Suite · OWASP ZAP · Subfinder · Amass · ffuf  

🧪 **Labs:**
- TryHackMe: OWASP Top 10  
- PortSwigger Web Security Academy  

---

## 🧠 Stage 5: Advanced Cyber Security
🎯 **Goal:** Build pro-level skills.

**Learn:**
- Active Directory Attacks  
- Privilege Escalation (Win/Linux)  
- Reverse Engineering  
- Malware Analysis (Static/Dynamic)  
- Digital Forensics & Incident Response (DFIR)  
- SIEM, SOC Operations  

🧰 **Tools:**
BloodHound · Mimikatz · Volatility · Sysmon · Wireshark (Advanced)  

---

## 💼 Stage 6: Career & Certification Path
🎯 **Goal:** Prepare for professional cybersecurity roles.

**Top Certifications:**
| Level | Certification | Focus |
|--------|----------------|--------|
| 🟢 Beginner | CompTIA Security+ | Fundamentals |
| 🟡 Intermediate | CEH, eJPT | Hacking / Pentesting |
| 🔴 Advanced | OSCP, CISSP | Red / Blue Teaming |

💼 **Career Tips:**
- Create GitHub projects (scripts, labs, notes)  
- Build a cybersecurity portfolio website  
- Write blogs on Medium / LinkedIn
